## Why
PLAN P1-8 ("런타임 STATE/instance/events 스키마 - OD-8 종결 필요(§9 ADR 경로)") is open. `instance.json` has its frame and four members (ADR-0018, ADR-0020, ADR-0022, ADR-0023) and the rule for the layout version (ADR-0024), all implemented in `hilclaw/instance.py`, which reads and validates. **Nothing in the package writes the file, and no record says how its bytes come to be on disk**:

> **How the file comes to be on disk is not decided.** ADR-0014 decision 7 left it open for this file, and it goes with what writes it (sub-question ⑰). Until then nothing excludes a partial file after the death of a writer; such a file is invalid by the rule above and is reported. - ADR-0018 decision 2

- ADR-0013 fixed the replacement of `STATE.json` and ADR-0014 the writes of `artifacts.json` and of the two key record files; ADR-0014 decision 7 names `instance.json` among the files for which the question is "not decided" and says "a later record for such a file may refer to ADR-0013 and to this record instead of repeating them".
- OD-8 sub-question ⑰ (OpenDecisionProposals, line 97) asks three things: what writes `instance.json`; **by which steps it comes to be under its final name (the once-only step of ADR-0014 decision 3, the replacement of ADR-0013, or another) so that a death of the writer leaves no partial file**; and what a run directory that holds other files and not this one means. This task takes the **second** only.
- The file differs from the three covered ones in one fact: ADR-0004 calls it the "immutable instance record", written by "the start of the instance, once", and ADR-0020 / ADR-0022 say that nothing rewrites it. A partial file here is not repaired by a later rewrite, and a HW tool call about the run answers `run_file_invalid` (ADR-0019) for the life of the run.

DRIVER §6: a task that needs a design-level decision carries the record that closes it; the route used so far is two tasks (record, then code). **This task writes the record**, ADR-0025. It ticks **no PLAN checkbox** (P1-8 stays open: the writer, the start of an instance and the result files remain).
