## Why
PLAN P1-1 (the FR-10 tool contracts, the mock backend, the conformance tests) is open. `sim.run` and `board.run` have two records: **ADR-0061** (the split, the sample form from `objective`, the call that carries the memory figure and where it reads the `bound`, which outcomes are results; landed `8f971f1`, nits `d7a6090`) and **ADR-0062** (the identity of a call: both tools journaled, `step` values `sim_run_timing` / `board_run_timing`, the meaning of `execution`, the five request members, the order of a call; landed `02b35d1`, nits `69745a1`). Their code slices have landed: `hilclaw/run_objective.py` (T-0192), `judge_report` in `hilclaw/harness/timing.py` (T-0194, T-0198), `hilclaw/run_identity.py` (T-0196).

ADR-0061 Consequences item **(2)** and ADR-0062 Consequences item (2): "the result members, which carry the measurement, the state or condition, the figure, the verdict and *no ceiling stated* - the third clause of OD-13 sub-question 10", which, "the tools being journaled, are written to `events.ndjson` as the `result` of an end line: the point at which ADR-0061's A-13 reading said it would end, to be judged by that slice". ADR-0061 decision 7 already says what a result must let a caller tell apart and must never contain, and names no member. **This task is that slice**, as ADR-0042 was for `correctness.check` (ADR-0042 came before that tool's seed record ADR-0048 and its form-of-the-cut record ADR-0043; the same order is kept here).
