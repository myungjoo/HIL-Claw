## Why
PLAN P1-1 (the FR-10 tool contracts, the mock backend, the conformance tests) is open. For `correctness.check` the landed records are ADR-0021 (the split, the seed, the tolerance), ADR-0038 (the execution points), ADR-0040 (the identity of a call), ADR-0041 (the dimensions), ADR-0042 (the members of a result), ADR-0043 (the form between the tool function and an operation), ADR-0044 (the mock's side) and ADR-0045 (an answer of neither form). The code side holds every pure part of the judging path (`hilclaw.check_result`, `check_judging`, `check_answer`, `check_parameters`, `mock_check`, `check_operation`).

One value of every check has no source. A check is judged for, and an operation is handed, **a number of draws** (`draws`, an integer of at least 1 - ADR-0017 decisions 3 and 9; ADR-0021 decision 2, class (ii); ADR-0043 decision 2), and a result states it (ADR-0042 decision 5). No record says where a call has it from:

- ADR-0017 decision 3: "`draws`, a parameter of the run, at least 1, given by the caller with no default ... how many an instance uses is a trade of cost against assurance that no source fixes (sub-question 5)"; its Alternatives: "A constant number of draws - A value no source gives; the instance or the tool contract is where the trade is made."
- ADR-0021 decision 2: "Where `draws`, the dimensions, the flags and the time limits come from is not decided"; decision 3: "`draws` is not decided: how many a check of a round or a promotion-level re-verification uses stays with OD-16 sub-question 5".
- ADR-0042 decision 5, ADR-0043 decision 2 and ADR-0044 decision 5 each repeat: "no value, source or default of `draws` is fixed".

Every list of "what the next slices of the second record must still add" since ADR-0040 carries "where `draws` comes from", and the closed member list of a request, the input schema and the tool function itself cannot be written before it. **This task is the record for that one item.** It is the first planner follow-up of T-0136 and T-0137 ("`draws` (OD-16 sub-question 5): judge against DRIVER §9 first").

The task ticks **no PLAN checkbox**: P1-1 stays open, and the tool still cannot be registered after this record.
