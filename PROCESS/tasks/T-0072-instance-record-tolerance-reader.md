### Validity of the member (ADR-0020 decisions 2 to 4)
- `tolerance` becomes a defined top-level member of version 1: it is checked by `parse` and `validate` and is **no longer in `Instance.others`**.
- **Absent**: the content is valid and states no tolerance. `schema_version` stays 1; `SCHEMA_VERSION` is unchanged.
- **Present**: an object with **exactly** `rtol` and `atol`. A value that is no object (`null`, a number, a string, an array, `true`), a missing member, or any further member (a misspelt name included) makes the content invalid as a whole: `InvalidInstanceError`, nothing returned - not the hw_profile either.
- **Each value**: exactly an `int` or a `float` as `json.loads` returns it (`type(value) in (int, float)`, so `true`, `false`, `null`, a string, an array and an object are none); valid when its binary64 value is finite and not negative. An `int` that no `float` holds (`float(value)` raises `OverflowError`) and a literal read as an infinity (`1e999`) are invalid, never accepted as an infinity. Zero is valid for either and for both; `-0`, `-0.0` and `-1e-999` are zero and valid; `1e-999` is valid as zero. No upper bound and no relation between the two values.
- **The value handed out** is the binary64 number: a `float` for both members, also when the literal was an integer.
- **Order**: the rules for the whole text, then `schema_version` (another version is still `UnsupportedVersionError` before any other member is looked at, a broken `tolerance` included), then the members of version 1. The order between `hw_profile` and `tolerance`, and inside `tolerance`, is yours; state it in the module docstring. The first rule found broken is reported and names its place (for example `tolerance.rtol`), by the module's `_fail` conventions.
- Every other top-level member stays open and uninterpreted (`tolerence`, `tolerances`, `rtol`, `atol` at the top level included): passed over, returned in `others`, and the content then states no tolerance.
- `validate(document)` applies the same member rules to a parsed document. State in its docstring what it accepts for a value built in memory (a `float` infinity or NaN is invalid; a `bool` is none).
- The validator does not check that the run is of the first case and gives the member no other meaning (decision 2).
