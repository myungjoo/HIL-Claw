## Why

> **The code slice that can now be cut** (within the size cap, code mode): in `hilclaw/instance.py`, the validity of the member by decision 3 and a reader of the N of a run beside `n_max_of`, with tests in `tests/test_instance.py`. ### The validity of the member (ADR-0028 decisions 3 and 4)
