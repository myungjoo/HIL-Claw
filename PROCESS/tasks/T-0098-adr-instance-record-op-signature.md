What the ADR **decides**. The content of each decision is the executor's to work out and justify from the fixed inputs; the reviewer's Approve confirms it. For every point give the choice, the alternatives considered and one or two lines of reason; mark each value as **cited** (owner, or an earlier record - say which) or as **this record's own**:
1. **Scope**: of `runs/<run_id>/instance.json`, the one member in which a run states its op_signature; nothing else of the file and nothing of any other file. State that the file is still not a complete instance record (ADR-0018 decision 1).
2. **What the member states.** The op_signature the instance was started with: the key under which the run's knowledge is filed below `db/<hw_profile_key>/`. Say exactly what a reader of this record may conclude and what it may not: it does not say how the start came to the record (a model, a kernel spec file, a frontend - #5 B-5, OD-9), not the kernel contract or the kernel language (ADR-0008 decision 8: neither is in the key), not that a stored record exists under `db/` for it (compare ADR-0018 decision 6 "The copy and the stored record", line 73), not what any spec of the run carries, and not that the run is "of the first case" in the sense of ADR-0020 and ADR-0021 (the kind and the dtype become visible where the member is present; the kernel language does not). **Do not rewrite ADR-0020 decision 2 or ADR-0021 decision 1**: state what becomes less exact in them as a consequence.
3. **The member: its name, place and form.** Weigh at least: (a) a top-level `op_signature` object with exactly `key` and `record`, the form of `hw_profile` in this file and of `task.op_signature` in a spec, valid when `record` is a valid record by ADR-0001 (what `hilclaw.keys.op_signature_key` accepts) and `key` is the name derived from it; (b) the key alone - weigh it against ADR-0018's reasons for the full record (the stored record need not exist and attributes such as `label` can change under one key); (c) the record alone; (d) a member nested under `hw_profile` or a new enclosing object - weigh it against the fact that this would add a member inside `hw_profile`, which raises the version by ADR-0018 decision 2. Say what is no value.
4. **One op_signature or several; OD-6 sub-question 3.** Decide only as far as the fixed inputs carry. Weigh at least: (i) the member states exactly one op_signature in version 1, and whether an instance may cover several values of M (or several projection shapes) stays open under OD-6 sub-question 3 without being excluded, in the manner of ADR-0018 decision 5 - then say what a later answer "several" would cost (a new member or a new `schema_version`; OD-11); (ii) the member is a non-empty array - weigh it against the fact that a valid file with two entries would state something no record gives a meaning to (which spec, which measurement, which objective belongs to which entry), and against C-6; (iii) the record answers sub-question 3 with "one" from the owner's words "as instance parameter" and C-6 - **only if the quoted sentences carry that without a reading that is the owner's to make; attribute to the owner exactly the sentences quoted and present any reading as the record's own.** If none of these can be justified without the owner, return BLOCKED with the exact question.
