## Why

PLAN P1-1 (FR-10 tool contracts) is open. The run tools `sim.run` / `board.run` have seven records, ADR-0061 to ADR-0067, each with code (`hilclaw/run_objective.py`, `run_identity.py`, `run_result.py`, `run_seed.py`, `run_parameters.py`, `run_operation.py`, `mock_run.py`, `run_admission.py`). The tool functions still cannot be written: ADR-0067 Consequences lists as still open "the kinds of ⑲ (나), with what the tool function does with a tool failure an operation raises; the log of ⑲ (다); the setting values of ⑲ (라) with OD-14".

Part (나) of OD-18 sub-question ⑲ (registered by ADR-0061, text at `ARCHITECTURE/OpenDecisionProposals.md` line 331) asks for the kinds of the situations in which no timing executable can be had or started other than a build that ended not ok — the backend kinds of `correctness.check` (ADR-0056, ADR-0060) or kinds of this contract — and the situations an isolated environment adds (with ⑱ (다), OD-14 sub-question ①). ADR-0061 decision 7 already made these situations **tool failures** (S1 to S6, S9, S10 of ADR-0056 decision 5, read for the timing build) and left only "Which kinds" to ⑲ (나). ADR-0065 decisions 8 and 9 left "what the tool function does with a tool failure an operation raises — whether its step is ended with it, under which kind (... as ADR-0047 did for the check)" to the same slice, bound by its decision 8 (no end line holds `seed_not_drawn`, `objective_not_stated`, `objective_not_covered`); ADR-0067 decision 5 added `op_signature_not_stated`, `op_signature_not_covered` and `n_max_not_stated` to that list. ADR-0066 decision 5 left the kinds a mock script may raise unnamed for the same reason. For `correctness.check` the same pieces were ADR-0047 (operation tool failure, `operation_failure_invalid`), ADR-0056 decision 6 and ADR-0060 decision 4 (the eight backend kinds), with code `hilclaw/check_failure.py`.

This is the next closed piece of item (6) and needs no setting value or container design. It is part of OD-18, a design-level OD, not owner-only (DRIVER §9: owner-only means #5 A/B items, C-6, OD-25 and OD-3). Under DRIVER §6 and §9 this task therefore writes the ADR. The 2026-10-15 journal names "OD-18 sub-question ⑲ (na) (doc, §9 ADR)" as the next candidate.
