### The module (`hilclaw/mock_backend.py`)
Recommended shape (the names are yours to choose):
- **The reserved name**: one public constant, for example `NAME = "mock"`, with a one-line `#:` comment (ADR-0016 decision 5 (b)). It is a name in the sense of ADR-0001 (`backends.Backend` checks it). The spelling is this task's ("the sources give 'mock' as a word, not as a value of a record"); recommended `mock`.
- **The builder**: one public function, for example `backend(script, tools)`, which returns a `hilclaw.backends.Backend` whose name is the reserved name and which has one operation for each HW tool named in `tools`.
  - It takes **no name**: a mock backend has the reserved name and no other, and nothing else of this module builds a `Backend`.
  - `tools`: the HW tools this mock offers, an iterable of members of `backends.HW_TOOLS`; it may be empty (a mock that offers nothing — the way a test produces `not_offered`, decision 5 (d)). A name outside `HW_TOOLS` is refused when the backend is built, with what `backends.Backend` raises for it.
  - `script`: a callable. What is not callable is refused when the backend is built (`TypeError`) — also when `tools` is empty.
  - **Building asks the script nothing**, and neither does `backends.select`: the script is asked when an operation is called, once for each call.
- **The operation of a tool**: called with the request and the hw_profile of the call, it asks the script with **the called tool, the request and the hw_profile** and its outcome is the script's:
  - what the script returns is returned — the very object, not copied, not checked;
  - what the script raises passes through unchanged — a `tools.ToolFailure` of any kind, any other `Exception`, and a `BaseException` such as `SystemExit` or `KeyboardInterrupt` (the mock catches nothing, so a script that ends the process ends it: decision 5 (d), the death "while the operation runs").
  - The request and the hw_profile are handed to the script as they are; the mock modifies and keeps neither.
- **The mock adds nothing of its own** (decision 5 (e)): no clock, no random source, no counter, no file, no environment variable, no configuration; the module holds no backend, no table and no script at module level and keeps nothing between calls. From `hilclaw` it imports `backends` only (and `tools` only if a docstring reference or a type needs it).
- **Selected by the rule of decision 4 only**: the module offers no other way to reach a mock operation — no function that calls a script directly, no member of a request, no variable of the process. A test reaches an operation through `backends.select` with a table that holds the mock and a hw_profile record whose `accelerator` is the reserved name.
- The module defines **no default script, no default table and no tool**, and does not touch `tools.default_registry` (see `## Why`). It names no value of a hw_profile record but the reserved name.
