## Why
PLAN P1-1 (the FR-10 tool contracts, the **mock backend**, the conformance tests) is open. For `correctness.check` the landed records are ADR-0021 (the split), ADR-0038 (the execution points; a run at the mock is answered by this contract), ADR-0040 (the identity of a call), ADR-0041 (the dimensions), ADR-0042 (the members of a result) and ADR-0043 (the form between the tool function and an operation). On the code side `hilclaw.check_result`, `hilclaw.check_judging` and - since T-0133 - `hilclaw.check_answer` render the tool function's side of the cut.

What no record fixes yet is the mock's side. Every record of this line hands it on in the same words: "The default script and the rule by which it derives a report are the second record's" (ADR-0021 decision 2); "What the default script answers is the second record's" (the owner, HQ-0005 (4), in ADR-0038 decision 6); "**The default script, the rule by which it derives a report, and how the operation of the mock for this tool is written are the next slice's**" (ADR-0043 decision 6); and ADR-0043 Consequences lists "the operation and the default script of the mock" among what the next slices must add and says of the code: "*Possible after the next slice*: the operation of the mock for this tool, which is called with a third thing".
