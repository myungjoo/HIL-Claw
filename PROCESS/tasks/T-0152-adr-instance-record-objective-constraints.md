### The record (one new file `ARCHITECTURE/decisions/ADR-NNNN-od8-instance-record-objective.md`, next free number on `origin/main` at execution time; the slug may follow the member name chosen)
English; the "Record format" of ADR-0001 as ADR-0032 and ADR-0050 use it (Status, Context, Decision with Limits, an Example fenced as `json` - never as Python, `ruff format --check .` reads Markdown -, a short Walk-through, Alternatives considered, Consequences, Boundaries, References); about 130 to 180 lines. For every point give the choice, the alternatives weighed and one or two lines of reason.

The Decision section answers these points and only these:
1. **Scope.** Of `runs/<run_id>/instance.json`, the member (or members) in which a run states its objectives and its constraints; nothing else of the file and nothing of any other file. State that the file is still not a complete instance record (ADR-0018 decision 1).
2. **What the member states.** The target the instance was started with (FR-2), in the frame the owner fixed: a list of objectives beside a set of constraints. Say exactly what a reader of this record may conclude from a file that states it and what it may not: it is not the target metric of FR-3 axis 4 (a value at which a run stops), not a budget, not a tolerance, not a baseline, not `delta` (OD-13), not a statement that anything was measured or judged, and not a statement that a spec of the run carries the same value.
3. **Name, place and form.** Weigh at least: (a) one top-level member that is an object of the same shape as `task.objective` of ADR-0050 (so that "copied from the instance record" is a copy of one value); (b) two top-level members, one for the list and one for the set; (c) a form of its own that a spec writer translates. For the shape inside, say for each rule of ADR-0050 (decisions 2 to 5, checks 1 to 4) whether this file takes it **by citation** - so that the two files cannot drift - or states it again, and what follows for this file when a later record admits a type, a second entry, `weight` or `priority` in the spec (ADR-0050 decision 6): the planner's expectation, to be confirmed or corrected with reasons, is that the set of values an instance may state is at every moment the set a valid spec may carry, so that no instance can state what no spec can. **`memory_ceiling` stays not admitted here as long as it is not admitted there** (ADR-0052 decision 7; ADR-0050 L6): a file that states a constraint entry today is invalid, and the record says so plainly with its cost. The name is the record's choice: weigh the spec's word `objective` against names that would be read as FR-3 axis 4 (`target`) or as the round-loop's notion of a goal. The written form of an integer `bound` in this file: cite ADR-0051 decision 2 if the same spelling is taken, and say what is no value.
4. **A file without the member; the version.** By ADR-0018 decision 2's own rule. Weigh at least: (a) the member may be absent from a valid file, `schema_version` stays 1, absent means "no objective stated" - **never a default: a reader of this record never substitutes `latency_minimisation` or any other value**, and no path yields an objective the run did not state - and whether a run may start without one is the writer's and is registered; (b) the member is required and the file becomes version 2 - weigh FR-2 ("stated by the user for each Loop instance") and O3 ("an instance states exactly one objective") against the cost ADR-0032 decision 4 names (every file and reader of today is of another version; which layout version the new number states, ADR-0024 decision 3; reading another version is OD-11). Inside a present member, `constraints` absent versus empty: follow ADR-0050 decision 4 or argue the difference. A present and invalid member makes the file invalid as a whole (precedents: ADR-0020 decision 3, ADR-0032 decision 4). **If the executor or a reviewer concludes that only (b) is consistent with the owner's sentences, do not land a record: return BLOCKED ("data plane schema change / requirement unclear") with the exact question** - a new version of `instance.json` is not taken on the D6 route without the owner.
